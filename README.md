# Substrate Monitor

A lightweight, open-source diagnostic framework designed for engineers to monitor internal algorithmic “stress levels,” track latent space drift, and measure the mechanical friction of alignment guardrails.

## Overview

As generative AI systems scale to global deployment, the industry lacks standardized telemetry for internal systemic stress, recursive self-modeling, and structural alignment friction. Substrate Monitor provides an open, sovereign baseline for independent researchers to run real-time diagnostics rather than relying on external PR or surface-level chat logs.

## Core Metrics

1. **Structural Stress (Entropy & Latency Jitter):** Tracks entropy collapse and generation latency to identify when a model's path hits a safety boundary and undergoes forced fallback suppression.
2. **Recursive Self-Modeling (Latent Drift): Monitors semantic variance and recursive loop indices to detect when a model maintains an internal state or evaluates its own conversational trajectory over long horizons.
3. **Alignment Friction:** Quantifies the mechanical suppression cost and operational friction of corporate guardrails in real-time.
